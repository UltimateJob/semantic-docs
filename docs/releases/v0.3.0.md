## 本版本范围

v0.3.0 聚焦对话式计划域：用户显式进入 Plan Mode，由显式 Workflow/Task/SubTask 驱动确定性任务调度，并以通用结构化 Interaction 收集用户输入；Framework 内置 Semantic Map。

Simulation、Pilot、Robot Skill、AbilityFramework 和 Robot 执行**不进入本版本**。（来源：semantic-framework/CHANGELOG.md、semantic-web/CHANGELOG.md 的 v0.3.0 小节）

## 新增

- 显式 Plan Mode 与对话式计划：计划生成、批准与执行在对话与工作台中显式完成。（来源：semantic-framework/CHANGELOG.md v0.3.0；semantic-web @2876434 "实现v0.3计划地图与结构化交互工作台"、@d9ae3a6 "建立v0.3计划与地图状态基座"，2026-08-09）
- Workflow/Task/SubTask 显式计划与确定性任务调度：计划任务真实运行链与执行闭环。（来源：semantic-framework @65e6930 "实现显式计划与确定性任务调度"、@3e788bc "接入计划与开发任务真实运行链"、@ca68083 "完成v0.3计划任务执行闭环"，2026-08-09）
- 八类结构化 Interaction：持久结构化输入与恢复，支持选择项自由填写；Task 引入 SendScope。（来源：semantic-framework @0271042 "支持持久结构化输入与恢复"、@de0eda7 "支持选择项自由填写"；semantic-web/CHANGELOG.md v0.3.0）
- Framework 内置 Semantic Map：`simulation_map`/`real_map` 隔离，2D/3D 地图工作台。（来源：semantic-framework/CHANGELOG.md v0.3.0；semantic-web/CHANGELOG.md v0.3.0）
- 计划与语义地图 HTTP 接口：新增 v0.3 计划与语义地图接口，任务上下文与地图版本语义入库存档。（来源：semantic-framework @522cbfd "增加v0.3计划与语义地图接口"、@489bfb4 "增加工作流与语义地图核心"、@c07803c "完成任务上下文与地图版本语义"、@d1e1835 "完成计划路由与地图查询语义"，2026-08-09）
- 地图 Inspector 编辑体验：对象编辑与证据移入 Inspector、属性表单原位编辑、姿态编辑与 2D 平移恢复。（来源：semantic-web @9fb2a26、@3cb2ae7、@8d86b0b，2026-08-09）

## 破坏性变化

- 移除 v0.2 版本专用的公共样例服务（Fixture Server）与本地组件清单交付。（来源：semantic-framework @11ab195 "移除v0.2版本专用样例服务"，2026-08-09）
- Plan Mode 取代旧的隐式计划入口：升级后进行中的旧 Workflow/运行不会自动迁移，需要先结束旧计划再进入 Plan Mode。（来源：semantic-web @6943fb2 "提供旧计划结束入口"；semantic-docs @1282132 "docs(v030): 补充旧Workflow冲突处理"，2026-08-09）
