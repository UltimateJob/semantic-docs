## Scope

The v0.4.0 spine is **simulation and scene authoring**: Framework merged `feature/v040-simulation-and-authoring`, Web merged `feature/v040-simulation-workbench` (both into develop on 2026-08-12). In the same window, the Pilot/Robot execution chain was already developing on develop, but its Gate tests were named v0.5 (semantic-framework @b63bb64, 2026-08-11) and productization is recorded in v0.5.0.

## Added

- Studio simulation workbench: MuJoCo workspace, simulation resource refactor, and local Physics Viewer. (Source: semantic-web @9cd09ac, @b972790, 2026-08-09~08-12; semantic-framework @b1832a0, @71a2a4e)
- Runtime Pack and isolated Profiles: MuJoCo Runtime refactored to a unified scene stream, with Runtime Packs isolated by Profile. (Source: semantic-simulation/mujoco-runtime @f85cceb, @144e6c6, 2026-08-12)
- Scene asset system: v0.4 depalletizing Scene and Layout templates, versioned Franka Panda model packages, unified Native Scene Package manifests, and asset-extension rules. (Source: semantic-scene/mujoco-asset @4027725, @1720b4f, @1eb9cb2, @9c2fb7c)
- Studio device and Skill integration: device workbench in the activity bar, unified Agent and Robot Skill browsing, unified Robot Skill detail and deploy views, and a Robot Execution timeline. (Source: semantic-web @bd9492f, @1fa86c5, @2d6febf, @3bcb4c4, @6af87f9, 2026-08-12~08-13. TODO(confirm): whether the device workbench shipped with public v0.4.0.)
- Review and execute plans in the conversation flow. (Source: semantic-web @0c8eac7, 2026-08-12)
- Pilot capability discovery and evidence: discover Actions from Ability Manifests, report Robot/Ability metadata, expose Skill details and Stage evidence, and emit structured safe-stop evidence. (Source: semantic-framework @e4a34fd, @c0623ab, @5f90842, @a0f059c, 2026-08-12)
- Robot SDK baseline: optional WebSocket transport, environment-variable override of the Robot SDK endpoint, multi-Robot deploy notes, and Wheel usage. (Source: semantic-robotsdk/robot-sdk @80ddfac, @b9b1e07, @68406e4, 2026-08-11)

## Breaking changes

- Removed the production Mock demo entry. Pilot no longer provides a built-in Mock demo chain. (Source: semantic-framework @ed07bee, 2026-08-12)
- Pilot parses SKILL document definitions only. (Source: semantic-framework @07b156f, 2026-08-12)
- MuJoCo Runtime API converged to a unified scene stream. Integrations that called old plugin-mujoco APIs need adaptation. (Source: semantic-simulation/mujoco-runtime @f85cceb, 2026-08-12. TODO(confirm): field differences.)

## Configuration migration

- Robot SDK endpoint can be overridden by environment variables, so deploy scripts no longer need hardcoded addresses. (Source: semantic-robotsdk/robot-sdk @b9b1e07, 2026-08-11)

## Action Schema changes

- Ability Actions are declared by Manifest, and task parameter metadata is published. (Source: semantic-ability/r1pro-ability @43500eb, @49ddf40, 2026-08-12)
