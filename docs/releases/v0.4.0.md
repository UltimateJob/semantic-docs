## 本版本范围

v0.4.0 的主线是**仿真与场景创作**：Framework 合并分支 `feature/v040-simulation-and-authoring`，Web 合并分支 `feature/v040-simulation-workbench`（均于 2026-08-12 并入 develop）。同一时间窗内，Pilot/Robot 执行链已在 develop 上并行开发，但其 Gate 测试以 v0.5 命名（semantic-framework @b63bb64 "add real dual Robot v0.5 Gate"，2026-08-11），产品化记入 v0.5.0。

## 新增

- Studio 仿真工作台：MuJoCo 仿真工作区、仿真资源重构与本地 Physics Viewer（本地视觉链）。（来源：semantic-web @9cd09ac "完成v0.4仿真工作台"、@b972790 "重构Studio仿真资源与本地Physics Viewer"，2026-08-09~08-12；semantic-framework @b1832a0 "完成v0.4仿真管理与场景创作"、@71a2a4e "完成Runtime Pack、场景资源与本地视觉链"）
- Runtime Pack 与隔离 Profile：MuJoCo Runtime 重构为统一场景流，支持按 Profile 隔离的 Runtime Pack。（来源：semantic-simulation/mujoco-runtime @f85cceb "重构 v0.4 MuJoCo Runtime 与统一场景流"、@144e6c6 "增加隔离 Profile 与 Runtime Pack"，2026-08-12）
- Scene 资产体系：v0.4 拆码垛场景与 Layout 模板、Franka Panda 版本化模型包、Native Scene Package 清单统一与素材扩展规范。（来源：semantic-scene/mujoco-asset @4027725、@1720b4f（2026-08-12）、@1eb9cb2、@9c2fb7c（2026-08-13））
- Studio 设备与技能整合：设备工作台进入 Studio 活动栏，统一浏览 Agent 与 Robot 技能，Robot Skill 详情与部署视图统一，Robot Execution 时间线可查看。（来源：semantic-web @bd9492f、@1fa86c5、@2d6febf、@3bcb4c4、@6af87f9，2026-08-12~08-13。TODO(确认)：设备工作台提交发生在 0.3.0-dev 标记之后、0.4.0-dev 收口之前，是否随 v0.4.0 对外交付需负责人确认。）
- 对话流中审阅并执行计划：计划审阅与执行入口移入对话流。（来源：semantic-web @0c8eac7 "在对话流中审阅并执行计划"，2026-08-12）
- Pilot 能力发现与证据：从 Ability Manifest 发现 Action、上报 Robot/Ability 元数据、对外暴露 Skill 详情与 Stage 证据、输出结构化安全停止证据。（来源：semantic-framework @e4a34fd、@c0623ab、@5f90842、@a0f059c，2026-08-12）
- Robot SDK 基座：WebSocket 传输可选、支持环境变量覆盖 Robot SDK endpoint、多 Robot 部署与 Wheel 用法说明。（来源：semantic-robotsdk/robot-sdk @80ddfac、@b9b1e07、@68406e4，2026-08-11）

## 破坏性变化

- 移除生产 Mock 演示入口：Pilot 不再提供内置 Mock 演示链路。（来源：semantic-framework @ed07bee "移除生产Mock演示入口"，2026-08-12）
- Pilot 仅解析 SKILL 文档定义：Skill 能力来源收敛为 SKILL 文档。（来源：semantic-framework @07b156f "仅解析SKILL文档定义"，2026-08-12）
- MuJoCo Runtime API 收敛为统一场景流：直接调用 plugin-mujoco 旧接口的集成代码需要适配。（来源：semantic-simulation/mujoco-runtime @f85cceb，2026-08-12。TODO(确认)：旧接口与统一场景流的字段差异明细。）

## 配置迁移

- Robot SDK endpoint 支持环境变量覆盖，部署脚本可不再硬编码地址。（来源：semantic-robotsdk/robot-sdk @b9b1e07，2026-08-11）
